YouTube Music Native

In the native app, enable Local API and create a playback-control pairing code named Stream Deck.

Use the installed command or its full executable path. No arguments. On macOS this is the executable inside the app’s Contents/MacOS folder.

Connecting to Stream Deck…

The token stays in your system keyring. Forget disables automatic connection and removes that saved token. Revoke Stream Deck in the native app’s Local API settings to invalidate access.

Volume keys change volume by 5%. The Volume / Mute dial changes volume by 2% per tick; press or tap to mute. Now Playing shows track and artist; press it to show the native app.
